🔌 Widget Types

Window

Root container with anchoring system

widget.window.[name]

Button

Interactive element with script execution

widget.button.[name]

Dynamic Label

Auto-updating text from scripts

widget.dynamic-label.[name]

WidgetBox

Container for organizing child widgets

widget.widgetBox.[name]

🪟 Window Configuration


widget.window.[main] [
  anchor=["top", "left", "right", "bottom"]  // Full screen
  child="toolbar, content_box, status_bar"
  exclusivity="exclusive"
]
Property Values Description
anchor Array of positions Window anchoring points (full screen when all 4)
child Widget names Comma-separated list of child widgets
exclusivity "exclusive" Window behavior mode

🖱️ Button Configuration


widget.button.[shutdown] [
  child="dynamic-label.[shutdown_text]"
  onclick-event="systemctl poweroff"
]
Property Values Description
child Widget name Label or dynamic-label to display
onclick-event Script path/command Bash/Python/Rust script to execute

🔄 Dynamic Label


widget.dynamic-label.[time_display] [
  script-path="~/scripts/get_time.py"
  update-timing="1"
]
Property Values Description
script-path File path Script to execute (Bash/Python/Rust)
update-timing Seconds Update interval in seconds

📦 WidgetBox Container


widget.widgetBox.[status_bar] [
  child="network_status, cpu_usage, battery_level"
]
Property Values Description
child Widget names Space-separated list of child widgets
